## Defect found and fixed

**The Code Agent answered only the first topic in a question.** "What are the
most recent commits and did the latest CI/CD workflow runs pass?" returned only
commits, and "Which pull requests are open and what is their check status?"
returned only a PR count. This is the same pattern fixed for Monitoring in OPU-51.
`CodeAgent.ask()` now answers every topic mentioned (commits, deployments, CI,
pull requests), includes per-PR CI status when asked (bounded to 3 PRs), and
reports a failed topic as "Couldn't read <topic> from GitHub." without backend
detail. Keyword matching uses word boundaries, so "procedure" still does not
match PRs. Single-topic answers keep the previous flat `data` shape. Tests:
`tests/test_code_agent_ask.py`; `pytest tests -q`: 317 passed, 1 skipped.
