## Read-only identity

The agent does **not** use the admin kubeconfig. A dedicated identity was created:

- ServiceAccount `opsbrain-readonly/opsbrain-infra-reader`
- ClusterRole `opsbrain-infra-reader`: `get`/`list` on `pods`, `nodes`,
  `apps/deployments`, `metrics.k8s.io/{pods,nodes}`; bound cluster-wide
- `kubectl auth can-i` as that account: get pods/deployments/nodes **yes**;
  delete pods, create deployments, get secrets **no**

The kubeconfig is self-contained (CA data + 24h token from `kubectl create token`)
at `~/.kube/opsbrain-infra.yaml`, mode 600, outside the repo; its contents were
never printed. Regenerate the token after it expires (24h).

## Commands

```bash
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/download/v0.8.0/components.yaml
kubectl -n kube-system patch deployment metrics-server --type=json \
  -p='[{"op":"add","path":"/spec/template/spec/containers/0/args/-","value":"--kubelet-insecure-tls"}]'
# RBAC as above, then a kubeconfig built from the CA and `kubectl create token --duration=24h`
KUBECONFIG_HOST=$HOME/.kube/opsbrain-infra.yaml docker compose \
  -f docker-compose.yml -f docker-compose.kafka.yml -f docker-compose.kubernetes.yml \
  --profile full up --build -d infra-agent
```

## Defects found and fixed

1. **Health answers listed only failures.** With AWS unavailable, a cluster health
   question returned "Infra health: degraded — failed checks: ec2, eks, rds" and
   dropped the healthy Kubernetes results it had already fetched.
   `_format_health_summary` now appends each passing check's summary (and skips
   any payload it cannot format). Test added in `tests/test_infra_agent.py`.
2. **An AWS unit test depended on the developer's machine.**
   `test_get_health_summary_reports_each_check_independently` assumed no
   kubeconfig and failed once `~/.kube/config` existed. It now points at a
   missing kubeconfig explicitly.

`pytest tests -q`: 313 passed, 1 skipped. Changed files pass `ruff check`
(8 lint errors already existed elsewhere and were not touched).
